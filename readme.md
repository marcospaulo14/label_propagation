## 1. Clonar o repositório e criar o ambiente Conda

Clone o repositório:

```bash
git clone https://github.com/marcospaulo14/label_propagation
cd label_propagation
```

Crie o ambiente Conda utilizando o arquivo `requirements.yml`:

```bash
conda env create -f requirements.yml
```

Ative o ambiente:

```bash
conda activate label_propagation
```

Execute o programa:

```bash
python label_propagation.py
```
